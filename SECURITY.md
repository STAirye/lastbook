# Security policy

## Report a vulnerability

Please use [GitHub’s private vulnerability reporting form](https://github.com/Immortal-Protocols/lastbook/security/advisories/new) to report a suspected security vulnerability in Lastbook. Keep vulnerability details in that private report and use public issues for ordinary bugs and feature requests.

Include the Lastbook version, operating system, affected feature, and what you observed. If you have a crash log or screenshot, remove credentials and personal information before attaching it. We’ll use the private report to coordinate follow-up and disclosure.

Thank you for helping keep Lastbook and its users safe.
